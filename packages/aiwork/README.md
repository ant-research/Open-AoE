# AiWork 安装包 / Installation Packages

## 中文

- **技能：** 技能中心 → 集市 → 搜索 `openaoe数据助手`。
- **专家：** 专家社区 → 专家 → 分别搜索 `人类数据转换专家` 和 `具身模型训练专家`。
- **手动安装：** 下载下方 ZIP，在 AiWork 的“添加技能”或“添加专家”中选择上传入口，导入对应安装包。搜索不到时也可以直接安装。

点击文件链接后，使用代码库文件页的下载按钮保存 ZIP。也可克隆仓库，直接从本目录获取三个完整安装包。

详细步骤：[Skill 最佳实践](../../docs/aiwork-skill-best-practices.zh-CN.md) · [Expert 最佳实践](../../docs/aiwork-expert-best-practices.zh-CN.md)。

## English

- **Skill:** Skill Center → Marketplace → search for `openaoe数据助手`.
- **Experts:** Expert Community → Experts → search separately for `人类数据转换专家` and `具身模型训练专家`.
- **Manual installation:** Download the ZIP files below and use the upload option under **Add Skill** or **Add Expert** in AiWork. This also works when search returns no match.

Open a file link and use the repository file page's download button to save the ZIP. You can also clone the repository and use the three complete packages in this directory.

Detailed steps: [Skill guide](../../docs/aiwork-skill-best-practices.md) · [Expert guide](../../docs/aiwork-expert-best-practices.md).
